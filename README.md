# إدارة مزرعة الأرانب — تحديث

## نشر GitHub Pages داخل مجلد docs
1. فك ضغط ملف التحديث.
2. افتح repository على GitHub وأنشئ مجلد `docs` (أو افتحه إن كان موجودًا).
3. ارفع **محتويات هذا الملف المضغوط مباشرة داخل docs**؛ يجب أن يكون `index.html` داخل `docs` مباشرة.
4. Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.

## الإضافات في هذه النسخة
- تعديل بيانات الأرنب من زر «تعديل» مع التحقق من عدم تكرار المسلسل.
- ملف الأرنب: الأم والأب، السلالة، تاريخ الميلاد، تاريخ التشغيل، القفص والعين، عدد البطون، الحالة والملاحظات.
- عرض سجل بطون الأم وإجمالي إنتاج السنة الحالية.
- القفص يدعم عدد العيون، وتسجيل الأرنب على القفص والعين.
- حاسبة العلف حسب فئات عمر/حالة، أو تقدير للقطيع المسجل تلقائيًا: خلفة أقل من 35 يومًا، نمو حتى 120 يومًا، بالغ، حامل (تلقيح إيجابي دون ولادة مسجلة)، مرضعة (ولادة لم تسجل فطامها). يمكن تعديل معدلات الجرام/اليوم من الإعدادات.
- سجل الصحة يضيف خانة المرض/التشخيص إلى التحصين والعلاج.

## ملاحظات
- معدلات العلف الافتراضية داخل الحاسبة تقديرية فقط؛ عدّلها وفق العلف المستخدم وإرشاد الطبيب البيطري. حاسبة القطيع تستخدم بيانات الولادات والتلقيحات المسجلة.
- بيانات الموقع محفوظة محليًا في متصفح الجهاز، لذلك لا يوجد تزامن تلقائي بين أجهزة مختلفة.
- احتفظ بنسخة JSON من صفحة الإعدادات دوريًا.
- هذه نسخة تطوير: QR والطباعة PDF، تسجيل النفوق/الاستبعاد التفصيلي، وإدارة متعددة المستخدمين ما زالت تحتاج تنفيذًا.
